Courses MCP is a locally hosted MCP server specifically designed for FINKI students. It is the connection between your AI agent and the Courses platform. With the help of an application that supports MCP, you can pose your queries to the agent, and the agent will use its software to find the necessary information from the courses you are enrolled in.

I have designed Courses MCP with the intention of making our lives as students easier. Instead of logging in and searching through our courses each and every time, we could just ask our agent to provide us with the information we need.

## How it works

The Model Context Protocol, or MCP, allows a client application to invoke tools offered by the server. Courses MCP offers tools to help you navigate your course(s) and access data from Moodle.

<ConnectionFlow />

The server is run locally by your computer. It is started by your MCP client as a local process and interacts with it via standard input/output. At the first invocation of the tool, the server logs into the faculty CAS and maintains the session until shutdown.

## Access and privacy

You enter your faculty credentials locally. Use them in the server configuration for the project and don’t share them in chats and shared documents.

Moodle access is read-only. Personal attendance and preferences for the term can be saved locally if you ask for this explicitly. Access to courses is defined by your faculty account permissions.
