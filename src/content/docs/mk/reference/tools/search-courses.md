Пребарувајте низ мала група предмети кога не знаете во кој се наоѓа информацијата. За разлика од [search_course](/mk/reference/tools/search-course/), оваа алатка враќа рангирани текстуални извадоци и може да вклучи поддржани HTML или PDF материјали што изречно ќе ги изберете.

## Изберете го опсегот

Користете [list_courses](/mk/reference/tools/list-courses/) за да изберете ID на запишани предмети. Со [get_course](/mk/reference/tools/get-course/) пронајдете ги линковите до материјали пред да изберете документи.

Пребарувањето не го чита автоматски секој поврзан документ. Во `documents`, користете го нумеричкото ID на курсниот модул од пронајдениот URL како `resourceId`, наместо структурираното поле `id` на материјалот.

## Параметри

| Параметар | Тип | Задолжителен | Значење |
| --- | --- | --- | --- |
| `courseIds` | number[] | Да | Од 1 до 4 ID на запишани предмети. Секое мора да е позитивен безбеден цел број. |
| `query` | string | Да | Од 1 до 200 знаци по отстранување на празните места на почетокот и крајот. |
| `limit` | number | Не | Максимален број совпаѓања: цел број од 1 до 30. Стандардно е 10. |
| `documents` | object[] | Не | До 3 избори `{ courseId, resourceId }`. Двете ID се позитивни безбедни цели броеви. Предметот мора да е избран и да остане во опсегот на филтрите. |
| `academicYear` | string | Не | Последователни години во формат `YYYY/YYYY`, на пример `2026/2027`. |
| `semester` | string | Не | `winter` или `summer`. |
| `refresh` | boolean | Не | Повторно изгради го индексот од тековните извори. Стандардно е `false`. |

Филтрите за година и семестар ги стеснуваат избраните ID според ознаките во името и краткото име на предметот. Не додаваат други предмети и не заклучуваат кој е семестарот според денешниот датум. Непознатите или противречни ознаки се пријавуваат во `selection.unclassifiedCourseIds`.

## Пробајте во вашиот клиент

> Пронајди каде се спомнува рекурзија во овие два предмета.

```json
{
  "courseIds": [123, 456],
  "query": "рекурзија",
  "limit": 5
}
```

За да вклучите конкретен пронајден документ:

```json
{
  "courseIds": [123],
  "query": "рекурзија",
  "documents": [{ "courseId": 123, "resourceId": 789 }]
}
```

Сите ID погоре се примери. Заменете ги со ID на запишани предмети и ID на курсниот модул од пронајдениот материјал.

## Прочитајте го резултатот

| Поле | Значење |
| --- | --- |
| `status` | `read` или `partial`, според покриеноста на пребараниот опсег. |
| `matchStatus` | `found` кога има совпаѓања; инаку `no_match` при целосна покриеност или `unknown` при нецелосна покриеност. |
| `matches` | Рангирани извадоци со `courseId`, `courseName`, `sourceName`, `url`, `page`, `excerpt`, `score` и `checkedAt`, како и идентификатори на индексот. |
| `truncated` | Пронајдени се повеќе совпаѓања од зададеното ограничување. |
| `coverage` | Статус по предмет, време на проверка, информации за изворите, предупредувања, недостапни ID на материјали и дали индексот бил повторно употребен. |
| `selection` | Побарани, пребарани, исклучени и некласифицирани ID на предмети, со филтрите и изворот на класификација. |
| `scope` | Опис на содржината вклучена во пребарувањето. |

Пребарувањето користи нормализирани зборови без разлика меѓу големи и мали букви. Извадокот може да содржи само дел од бараните зборови; оценката ги брои различните зборови од прашањето што се присутни. Рангирањето е според клучни зборови, без додавање синоними или преведување.

При цитирање користете го вратениот URL на изворот. PDF извадоците имаат број на страница; извадоците од страници на предмети и HTML користат `page: null`. Извадокот не е целиот документ.

## Покриеност и освежување

Серверот го проверува запишувањето и ги чита тековните извори на предметот пред да разгледа зачуван индекс. Кога кеширањето на индекси е вклучено, индексот може повторно да се употреби само ако се совпаѓа отпечатокот на изворите. `refresh: true` наложува повторна изградба; не овозможува читање неподдржана содржина.

Опсегот го опфаќа видливиот текст на предметите и изречно избраните поддржани HTML/PDF материјали. Другите документи и содржината на папки остануваат надвор од пребарувањето. Ограничувањата на читањето и индексирањето може да дадат делумна покриеност, затоа проверете ги предупредувањата и статусите на изворите и кога има совпаѓања.

Празен резултат се однесува само на пријавениот пребаран опсег. Ако сите побарани предмети се исклучени со филтрите, проверете го `selection` пред да заклучите нешто. Предмет на кој не сте запишани или документ надвор од избраните предмети и филтри предизвикува грешка. Пристапот до Moodle е само за читање.
